## Project Version 2.0

1. We would try to integrate several PCBs in the rover into 1 single PCB, which would be helpful for more robust and smoother work. We would also try to integrate the HMI into 1 PCB that includes the MQTT.
<br>
2. We would try to have the pressure and accelerometer sensor working, and since we were not able to integrate it into our subsystem, having this would be amazing to meet all of our project plans and requirements.
<br>
3. We would make sure that the team would use the same footprint for the 8-pin ribbon connectors. This would allow us to use fewer extra wires and spend less time connecting the boards. Also, when connecting ribbon connectors to boards, there is almost no chance of shorting any boards.
<br>
4. The temperature sensing probe would be more accurately calibrated for higher precision measurements. Smoothing code would be added to prevent the user from seeing the induced noise. <br>
5. HMI control and communication would be accomplished via radio to allow for greater operational range in agricultural environments.<br>
6. A version would be made with fiber optic control, and communication would be made to allow operation in environments where radio frequencies could be damped, such as mines.<br>
7. GPS capabilities would be added to aid in mapping and recording data collection locations.<br>
8. More powerful motors would be selected to allow the rover to traverse rougher terrain.<br>
9. More time would be spent developing a clear power distribution strategy. During the project, there was uncertainty about when it was safe to share power due to confusing jumper configurations and unclear silkscreen labeling. TVS diodes and other ESD protection components would also be added in smart locations to reduce the risk of damage and improve system reliability.<br>
